Receitas Fantásticas e Como Fazê-las

O intuito é compilar diversas receitas mágicas do mundo de Harry Potter, e o livro contém imagens delas, os ingredientes necessários para prapará-las e também as instruções passo-a-passo.
O aplicativo conta com 5 possíveis escolhas de receitas, sendo elas 3 comidas e 2 bebidas, cada uma com sua página específica. No total, há 6 telas, e, a cada vez que uma das receitas é escolhida, o dispositivo vibra.
